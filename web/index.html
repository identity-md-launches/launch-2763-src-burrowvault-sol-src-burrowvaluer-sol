Sepolia · read the deployed source

Burrow lends SQK against Squeek NFTs. Collateral is escrowed, re-staked on Squeekchain with the vault as claim recipient, so mining rewards pay the debt down; rewards above the debt go back to the borrower. There is no NFT price feed on this chain, so valuation is power-based: the price per power unit is a governed parameter behind a 48-hour timelock, capped at 20% per change, and liquidation is frozen for an hour after any change.

Deployed source, tests and README: burrow-squeek.vercel.app/source; every contract is a Sourcify exact match. Unaudited. Sepolia testnet only, SQK has no value. The page reads the Squeekchain API and Sepolia over eth_call; Squeek art comes from the collection's own on-chain renderer.
